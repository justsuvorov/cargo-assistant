## Тестовые данные

Корень `{ROOT}` = `D:\Projects\document-assistant\`. Это **реальные данные клиента**: читать для
анализа можно, в репозиторий — только обезличенные производные.

| Что | Путь |
|---|---|
| Формы ответа | `{ROOT}\Формы ответа\Структура проверки декларации.xlsx`, `…\Структура проверки декларации ПСГ.xlsx` |
| Декларации с разметкой ФСЦ | `{ROOT}\cargo tests\unpacked\{N}\` для N = 005, 35, 70, 76, 97, 107, 113, 114, 263, 271 |
| Без разметки | `{ROOT}\cargo tests\unpacked\{N}\` для N = 164, 274 |
| Упавшие в MVP | `…\unpacked\7\`, `…\unpacked\29\` (лог в .txt), `…\unpacked\46 …xlsx` (имя в cp866) |
| Сводка MVP против разметки | `{ROOT}\cargo tests\Сверка нового прогона с замечаниями ФСЦ.xlsx` |
| Декларация → папка полиса у заказчика | `{ROOT}\cargo tests\new_versions tests\files.txt` (в конце файла — лог MVP) |

В папке `unpacked\{N}\`: исходная декларация (.xls/.xlsx, имена вида «N — копия.xls»,
«N маршрут.xls» в cp866), «N – результат проверки.xlsx» (ответ MVP + колонка «Комментарии ФСЦ»),
скриншот экрана MVP. ГП и ДС локально нет (вопрос П-1).

```
                   - ни одного или несколько кандидатов на ГП, два файла с одним номером ДС —
                     проблема в problems, а не молчаливый выбор; нет текста ГП вообще — ошибка;
                   - кодом из текста ДС: номер, дата вступления («вступает в силу с …»), декларации
                     области действия («по декларациям № 415, № 416»);
                   - проект (без даты подписания или вступления, как ДС 24) исключается и называется
                     в problems; вступление раньше подписания (ДС 23) — запись в problems, ДС не
                     исключается; опечатка в дате ГП вида «20.10.20217» разбор не роняет;
                   - скан без текста, нечитаемый файл, пустой документ — в problems; служебные файлы
                     (Thumbs.db, ~$…) и прочие приложения пропускаются;
                   - особые условия: .txt (utf-8, cp1251), .doc, .docx; перевозчики — по строкам;
                   - таблица в отчёте по трём реальным пакетам: найден ли ГП, номера ДС, область
                     действия, проблемы; без названий клиентов;
                   - все проверки из CLAUDE.md проходят.
Метрика:           по реальным пакетам: все подписанные ДС распознаны, проекты отсеяны.
Вне рамок:         модель, текст пунктов, профиль, загрузка через интерфейс.
```
